# 朋辈心理辅导案例分析 · 答题技能

## 0. 一句话说明

用户输入案例题干 → 直接输出**三段式答案**（问题 / 风险 / 帮助）。
- **答案正文**：可直接誊写，不含元话语、不含括号提示。
- **答案之后**：单独一小节「评分点自检」，6 条打勾，并注明"誊写时不要抄"。用户说"只要答案"时省略。

除非用户要求"讲讲思路"，否则**不要输出方法论说明、不要寒暄、不要反问**，考试只有 30 分钟。

---

## 1. 工作流（内部执行，不输出）

### 第 1 步：抽事实（30 秒）
从案例里抽出六类信息，写成内部清单：

| 维度 | 要抓的内容 |
|---|---|
| 人口学 | 年级、性别、专业、住宿情况、家庭结构 |
| 时间线 | 症状持续多久、有无明确诱因、起病急缓 |
| 症状 | 情绪 / 认知 / 生理 / 行为，逐条对号入座 |
| 功能 | 学业、人际、生活自理、睡眠饮食，受损到什么程度 |
| 风险 | 自杀/自伤言语与行为、无望感、既往史、孤立、重大丧失 |
| 资源 | 家庭、室友、朋友、老师、求助意愿、保护因素 |

**关键**：答案里每一条都要能回指案例原话或数据（"近三个月""体重轻了7斤""无数次想结束生命"）。这是得分的基本盘。

### 第 2 步：定层级（判断"是什么问题"）
用三原则 + 三标准，落到连续谱的某一档：

```
健康心理 → 一般心理问题 → 严重心理问题 → 精神障碍 → 心理危机
```

- **三原则**（判断"是否异常"）：统一性（主客观一致）、一致性（知情意协调）、稳定性（人格相对稳定）。
- **三标准**（判断"是哪一档"）：心理异常有无 + 社会功能受损大小 + 持续时间长短（能否自行缓解）。

**三原则的用法（容易写成套话）**：
- 案例**没有**幻觉、妄想、言行紊乱、人格突变 → 只用**一句话**带过："主客观统一、知情意基本协调、人格相对稳定，未见精神病性症状"，然后立刻转入三标准定级。**不要展开成一段。**
- 案例**有**上述线索（听见议论声、突然变健谈/挥霍、行为怪异）→ 才逐条展开三原则，并指出是哪一条被破坏。
- 定级的主力永远是**三标准**（条目数、功能损害、病程），三原则只在"要不要考虑精神病性障碍"这一步起作用。

**必须遵守的分寸（评分点）**：朋辈**不下诊断**。标准句式是
> "该同学的表现**符合/高度提示**抑郁发作的特征，**已达到需要专业评估的程度**，但是否构成抑郁障碍应由精神科医生诊断。"

写"她得了抑郁症"= 越界扣分；完全不提"可能是抑郁"= 漏分。

### 第 3 步：列风险（"需要注意哪些风险因素"）
按下面五类完整扫一遍，**宁可多写一条也不要漏掉自杀风险**：

1. **自杀/自伤风险**（永远排第一）
2. **病情恶化风险**（症状持续时间、条目数量、是否泛化）
3. **躯体健康风险**（体重、进食、睡眠、心身症状）
4. **功能与社会支持风险**（学业挂科、社交孤立、家庭沟通、病耻感）
5. **应对方式与伦理风险**（回避压抑、熬夜、酒精、要求保密→保密例外）

**两条分寸**：
- 若案例**确实没有**危机线索（如单纯学业拖延、宿舍小摩擦），不要硬造自杀风险，改写为："目前未见明确的自伤/自杀线索，但仍需关注情绪变化与孤立倾向"，然后照常写其余风险。
- 若案例里有**旁观者**，先分清角色：
  - **主动来求助的室友/同学** = 求助者，方案要加"如何与 TA 沟通了解情况"+"保护 TA 自己不被拖垮（信息边界、不承诺监护、必要时也找老师）"；
  - **只是提供信息的知情者** = 不写"保护求助者"，改为写"如何向室友核实情况、请其协助日常陪伴"。

### 第 4 步：生成帮助措施（分值最高）
用**分层 + 分主体**的结构，不要写成一段散文：

- **立即（安全）**：风险评估 → 不承诺保密 → 上报 → 24h 陪伴 → 移除危险物品 → 紧急热线/急诊
- **转介（专业）**：消除病耻感 → 告知资源 → 协助预约 → 尊重自主（邀请而非命令）→ 必要时陪同
- **持续（朋辈能做）**：倾听共情、小目标行为激活、低压力社交、优势视角、重建支持系统、定期跟进
- **边界（朋辈不能做）**：不诊断、不治疗、不承诺保密、不替代咨询师、不独自承担

### 第 5 步：自检（见第 5 节）后输出

## 2. 输出格式（默认严格照此）

### 2.1 篇幅与时间分配（30 分钟手写，务必遵守）

**字数口径：按汉字计，不含标点、标题与自检。** 手写速度按 **40–45 字/分钟** 估算，因此目标压到 **约 1150 字**，给检查留 3 分钟。

| 小问 | 分值（估） | 时间 | 汉字数 |
|---|---|---|---|
| 一、什么问题 | 15 | 8 分钟 | 330–400 |
| 二、风险因素 | 13 | 7 分钟 | 240–320 |
| 三、怎么做 | 16 | 12 分钟 | 430–540 |
| 检查 | — | 3 分钟 | — |

**总计 1050–1250 字**。写到 1300 以上大概率超时，低于 950 采分点不够。
`worked-examples.md` 的范文是"完整版"（约 1800 字），**考试时按上表压缩**：删块引用、删括号注释、"分阶段"压成半句。
时间不够时先砍第三问的修饰语，**绝不砍**：定性句、自杀风险、保密例外、转介资源、边界。

### 2.2 两个版本

- **完整版**（默认，时间充裕）：按下模板全写。
- **保命版**（只剩 10 分钟）：每问 3 条，只保留——
  ① 定性句（含"三原则 + 三标准"）② 自杀风险 + 保密例外 ③ 立即安全 + 转介 + 2 个具体资源 ④ 边界一句。
  骨架照抄，不要空着任何一问。

### 2.3 模板

```markdown
## 一、小A可能存在什么问题        ← 标题照抄题干中的称呼（小A/小B/该同学）

**总体判断**：按**三原则**（统一性/一致性/稳定性）判断有无心理异常，再按**三标准**（心理异常、社会功能受损、持续时间）判断落在哪一档，最后一句"高度提示……，需专业评估；朋辈不作诊断"。
例：小A 主客观统一、知情意协调、人格相对稳定，可排除精神病性障碍；但症状条目多、持续近三个月、社会功能明显受损，已超出一般心理问题，**高度提示抑郁发作**，属"精神障碍 + 心理危机"层级，需立即转介专业评估。

1. **情绪问题**：……
2. **认知问题**：……
3. **生理/躯体问题**：……
4. **行为与社会功能问题**：……
5. **发展性议题 / 需排除的其他可能**：……（写一句鉴别：双相史、甲减等躯体疾病、物质所致）

## 二、需要注意的风险因素

1. **自杀风险（首要）**：……（信号 + 四要素：频率强度 / 计划 / 手段 / 既往史）
2. **病情恶化风险**：……
3. **躯体健康风险**：……
4. **学业与社会功能风险**：……
5. **社会支持与求助障碍**：……
6. **伦理与保密风险**：……

**风险等级**：高 / 中 / 低 + 一句行动结论。
**保护因素**：一句。

## 三、可以做些什么去帮助小A      ← 同上，用题干称呼

**（一）立即：评估风险、确保安全**
**（二）转介：连接专业资源**
**（三）持续：朋辈能提供的支持**
**（四）边界：朋辈不做什么**
**（五）分阶段**（一句：紧急—短期—长期）
```

模板之外再附：

```markdown
---
**评分点自检（誊写时不要抄这一段）**
①三问齐全 ②每条有案例依据 ③未下诊断 ④自杀风险置顶+保密例外 ⑤措施具体 ⑥有边界与两个资源
```

### 2.4 誊写剥离规则
交卷时**只抄模板部分**。以下内容一律不抄：
- 块引用 `>` 里的例句与依据
- 括号里的"（可选）""（一句）"等提示
- 文末「评分点自检」
- 任何"根据……理论"式的开场

**但条目数要保留**：把诊断依据（如"已具备 8 项症状，持续远超 2 周"）**写进定性句或第一条里**，用正文句式，不要另起一段块引用。这是实打实的采分点。

### 2.5 题干关键词必须显式出现
若题干写"结合朋辈心理辅导的**识别与帮扶**知识要点"，答案中必须原样出现：
**识别**（症状识别、危机信号识别）、**帮扶**（朋辈帮扶、情绪急救）、**转介**、**伦理/保密例外**。
缺一个就丢一个采分点。

### 2.6 程度措辞的边界
- ✅ "程度**较重**""多项核心症状并存""提示需要尽快专业评估"
- ✅ "若达到重度水平，可能需要药物联合心理治疗（由医生判断）"
- ❌ "重度抑郁症""必须吃药""她已经病了"
- 若案例**无明显诱因**：写"起病无明显诱因，更提示存在生物学因素，应尽早就医评估"——这是加分论据，不是减分项。

## 3. 判断速查（内部查表用）

| 观察到的核心表现 | 首先考虑 | 关键阈值 |
|---|---|---|
| 心境低落 + 兴趣丧失 + 睡眠/食欲/体重/疲劳/自责/注意力/自杀意念 | 抑郁发作 | 连续 **2 周**，≥**5** 条，且含心境抑郁或兴趣丧失 |
| 过度担心难以控制 + 坐立不安 + 易激惹 | 广泛性焦虑 | 持续 **≥6 个月**，功能受损 |
| 突发心悸、濒死感、失控感 | 惊恐障碍 | 反复发作 + 回避 |
| 怕被负评、回避社交场合 | 社交焦虑 | **≥6 个月** |
| 高涨/易激惹 + 睡眠需求减少 + 话多 + 思维奔逸 + 鲁莽 | 双相（躁狂相） | **≥1 周**，≥3 条 |
| 幻觉/妄想/言语紊乱/阴性症状 | 精神分裂症谱系 | ≥2 项，**≥6 个月**，功能显著下降 |
| 强迫思维 + 强迫行为 + 反强迫 + 自知力 | 强迫障碍 | 耗时、痛苦、功能受损 |
| 重大事件 + 常规应对失效 + 无助无望失控 | 心理危机 | 挑战 / 困境 / 无效 三标准 |
| 明确应激事件后 1–3 个月内出现情绪行为症状，未达其他障碍标准 | 适应障碍 | **排除性诊断**，与抑郁/焦虑发作鉴别 |
| 酒/药使用后情绪行为改变 | 物质所致 | 需精神科评估 |

**鉴别写法（本题型的高分点）**：不要只判一个病。标准句式——
> "高度提示抑郁发作；同时需专业评估**排除双相障碍**（既往有无躁狂/轻躁狂史）、**适应障碍**（症状是否严格继发于应激事件且未达发作标准）、**物质或躯体因素所致**（饮酒、甲状腺功能等）。"

细节条目、危机信号清单、伦理与技能要点见 `references/knowledge-base.md`。

### 3.1 风险分级规则（结论要有证据，别凭感觉写"高"）

| 等级 | 判定条件（满足任一即达该级） | 行动 |
|---|---|---|
| **高** | 有**主动**自杀意念／有计划／有手段／**既往未遂史**／近期重大丧失后 1 个月内／严重失眠+体重骤降+无望 | 立即评估、启动保密例外、24h 不独处、当日上报、尽快转介 |
| **中高** | 只有**被动**死亡意愿（"活着没意思""没人在乎"）而无计划与既往史，但叠加孤立、饮酒、冲动、功能停摆 | 尽快完成风险评估、加密联系（隔天一次）、一周内转介 |
| **中** | 无自杀意念，但症状持续、功能受损、支持薄弱 | 转介 + 定期跟进 |
| **低** | 情绪反应有时限、可自缓解、支持良好 | 心理教育 + 保持关注 |

**写法**：先给等级，再用一句话点出**决定性证据**（"因存在反复自杀意念与累赘感，定为高风险"）。只写"高风险"而不给依据，是要扣分的。

## 4. 帮助措施生成器（保证不空泛）

每条建议必须能回答**谁 · 做什么 · 怎么做 · 多久**。把下面的"具体动作库"按案例裁剪：

**安全类**
- 私下、稳定时间、安全不被打扰的空间谈话
- 正常化："人在痛苦到难以承受时出现这样的想法是常见的"
- 温和而直接地问自杀意念（给话术，不要像清单）
- 问四要素：**频率强度 / 有无计划 / 手段是否可得 / 既往有无尝试**
- 不答应保密，说明保密例外与"有限内容、有限范围"披露
- **报告链条（按此顺序写）**：辅导员/班主任 → 学院（副书记/学工）→ 学校心理中心 → 家长 → 必要时精神科/急诊；紧急可直接拨保卫处或 110
- 安排 24 小时不独处；危险物品交由家长或辅导员协助管理
- 紧急：12356（全国）、96525（浙江）、0571-85029595（杭州）；必要时送急诊

**转介类**
- 解释"抑郁有生物学基础，不是意志薄弱"，降低病耻感
- 告知校心理咨询中心（xlzx.zju.edu.cn，0571-88982525）、校医院心理门诊、精神科
- 提供信息 + 邀请 + 尊重决定；**紧急时才陪同**，平时重在"陪伴而非替代"

**支持类（朋辈真正的主场）** —— 内部要有顺序，写"先情绪、再行为、后关系"：
- 倾听、共情（识别情绪 → 接纳观点 → 一起感受 → 不评论不分析原因）
- 具体小目标：固定起床时间、每天一顿正餐、晒太阳 10 分钟、记录一件"还行"的小事
- **低压力社交**：邀请一起吃饭/散步/自习（可拒绝），而不是"你多参加集体活动"
- 优势视角：从小成功切入（"你今天来上课了"），**不要**要求回忆昔日辉煌
- **陪伴要分工、要可行**：室友/同学负责**日常联络与结伴活动**（一起吃饭、上课、运动），**24 小时看护由辅导员与家长落实**——不要把监护责任压给室友。
- **每条持续性建议尽量带频率或时长**："每天一顿正餐""每天晒太阳 10 分钟""隔天发一条消息""每周面谈一次，持续两周"，比"定期跟进"多拿分。
- 联结室友、好友、家人。**与家长沟通的话术**："她最近状态很不好，不是不努力，也不是你们的错；医生说要先治病，这段时间她最需要的是被理解，而不是被催促。可以先做到：不追问成绩、每天一句关心、需要时陪她去医院。"
- 约定下一次联系时间，观察变化
- 朋辈自我照顾、寻求督导，不独自扛

**边界类**
- 不诊断、不治疗、不承诺保密、不替代咨询师、不擅自处理危机、不因同情而模糊多重关系

**反面清单（写了会扣分）**："想开点""别想太多""你要坚强""比你惨的人多的是""多出去走走就好了"；命令式"你应该……"；以"你"开头的指责句；以偏概全（"你总是……"）。

## 5. 评分点自检（放在答案正文之后，标注"誊写时不要抄"）

1. 三个小问是否**都**回答了，且顺序与题干一致？
2. 每条判断是否**引用了案例原话/数据**？
3. 是否用了"**提示/符合……特征，需专业评估**"，而不是下诊断？
4. 案例中有无自杀/自伤线索？**有则必须出现在"风险"第一条**，并写保密例外；**风险等级是否给出决定性证据**（而不是只写"高"）？
5. 帮助措施是否落到"谁、做什么、怎么做、**多久**"？有没有"多关心她""定期跟进"这类空话？
6. 是否写了**朋辈的边界**与**至少两个具体资源**？是否提到"室友不能承担监护责任"？

再加三条加分检查：**优势视角 / 正常化 / 保护因素** 是否各出现一次？**分阶段（紧急—短期—长期）**是否写了？是否至少有 **3 处本案独有的细节**写进了措施（见 §8.1）？

## 8. 输出风格约束

- 中文，书面语，术语准确（心境低落、兴趣丧失、无价值感、精神运动性迟滞、保密例外、转介）。
- 分点为主，每点加粗小标题，便于阅卷扫读。
- 不堆砌理论；理论只在"加分点"出现一句。
- 不写"作为 AI""以下是建议"这类元话语。
- 若题目要求"结合朋辈心理辅导的识别与帮扶知识要点"，答案中要显式出现"识别""帮扶""转介""伦理"这些关键词。

### 8.1 差异化锚点（避免模板化，必做）

每一份答案至少要有 **3 处只属于本案的细节**，并体现在措施里，而不只是复述症状。做法：

1. **抓本案独有的"抓手"**：独特诱因（失恋、挂科、亲人去世）、独特行为（饮酒、摔东西、退队、熬夜）、独特关系（父母不和、只信任某位室友）、独特语言（"没人在乎""我是累赘"）。
2. **把抓手写进措施**，而不是写成通用条目：
   - 通用："建议减少饮酒。" → 本案："和他一起记录每天饮酒量，先定'工作日不喝、周末最多两杯'的小目标。"
   - 通用："重建社会支持。" → 本案："他退出球队是重要损失，可先约他投篮，不逼他归队。"
3. **同一句话不要连续复用**。`worked-examples.md` 里的定性句、边界句可以借结构，但**换词**；同一段落里出现两处以上范文原句，就要改写。
4. **不要每个案例都从"按三原则……按三标准……"开头**——若无精神病性线索，直接写"从病程、条目数与功能损害看……"，更自然。
