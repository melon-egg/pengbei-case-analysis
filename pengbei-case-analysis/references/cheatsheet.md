# 考前 10 分钟速查卡

## 一、判断层级（三标准 + 三原则）
- **三标准**：心理异常有无 + 社会功能受损大小 + 持续时间长短（能否自缓解）
- **三原则**：统一性（主客观）、一致性（知情意）、稳定性（人格）
- 连续谱：健康心理 → 一般心理问题 → 严重心理问题 → 精神障碍 → 危机
- 一句话：**朋辈不下诊断，只说"符合……特征，需专业评估"**

## 二、抑郁速判
≥5 条 + 持续 ≥2 周 + 至少含①心境抑郁或②兴趣丧失 + 功能损害
九条：心境抑郁 / 兴趣丧失 / 体重变化 / 失眠或嗜睡 / 激越或迟滞 / 疲劳 / 无价值与内疚 / 注意不集中 / 自杀意念

## 三、危机信号（看到就写）
言语暗示想死（朋友圈）· 告别赠物安排后事 · 突然平静（最危险）· 无望绝望敌意 · 过度孤独 · 既往未遂史

## 四、风险六条（默认全写）
自杀 → 病情恶化 → 躯体 → 学业功能 → 社会支持 → 伦理保密例外

## 五、帮助四层
**立即安全**（评估—不保密—上报—24h 陪伴—移危险物—12356/96525）
→ **转介**（心理中心 0571-88982525 / 校医院心理门诊 / 精神科；去污名；尊重自主）
→ **持续**（共情倾听—小目标—低压力社交—优势视角—支持系统—跟进）
→ **边界**（不诊断、不治疗、不替代、不承诺保密）

## 六、话术
- 正常化："人在痛苦到难以承受时出现这样的念头，是很常见的。"
- 问自杀："是偶尔闪过，还是已经认真想过要怎么做？"
- 不保密："这件事关系到你的安全，我不能替你保密，但只会告诉必须知道的人，也会告诉你我说了什么。"
- 优势："你今天来上课了，这很不容易。"

## 七、绝不能说
"想开点""别想太多""你要坚强""多参加集体活动就好了""她得了抑郁症"
