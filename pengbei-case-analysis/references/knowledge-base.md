## 一、心理健康连续谱与分级

```
健康心理 → 一般心理问题 → 严重心理问题 → 精神障碍 → 心理危机
```

| 层级 | 特征 | 谁来做 |
|---|---|---|
| 健康心理 | 面对应激、压力、挫折、冲突、失败等生活事件，能自我调节 | 自我调节、他人疏导 |
| 一般心理问题 | 由现实因素激发，持续时间短，社会功能基本未破坏，情绪反应**未泛化** | **朋辈辅导**、心理咨询 |
| 严重心理问题 | 反应强烈、持续时间长、**已泛化**，难以自我调整 | 心理咨询 / 心理治疗 |
| 精神障碍 | 有临床可辨认的症状，伴痛苦与功能受损；本人常无自知力 | 精神科门诊 + 药物 / 住院 |
| 心理危机 | 重大事件 + 常规应对失效 + 无助无望失控 | 危机干预、转介 |

**心理问题定义**（中国心理卫生协会，2020）：由现实因素激发，持续时间短，没有严重破坏社会功能，情绪反应基本未泛化的心理不健康状态。

**精神障碍定义**（WHO, 2018）：临床上可辨认的症状或行为，多数情况下伴有痛苦和个体功能受损。

## 二、判断标准

### 2.1 精神障碍的三条判断标准
1. **心理异常**（有 / 无）
2. **社会功能受损**（对生活负面影响小 / 大）
3. **持续时间**（有一定时限、可自我调节或自行缓解 / 持续一段时间、无法自行缓解）

三条同时满足 → 倾向于精神障碍，需专业评估。

### 2.2 区分心理异常的三原则
| 原则 | 含义 | 反例（异常表现） |
|---|---|---|
| **统一性** | 主观世界与客观世界统一 | 听到窗台下有人议论，去看却没人——幻听 |
| **一致性** | 知、情、意协调一致 | 挂科后笑着说"果然我是个没用的人"——情感与认知不协调 |
| **稳定性** | 人格（个性）相对稳定 | 平素文静朴素，突然健谈、大手大脚花钱——人格稳定性破坏 |

## 三、常见精神障碍速查

### 3.1 抑郁障碍（高校最多见）
**抑郁情绪 vs 抑郁障碍**

| 抑郁情绪 | 抑郁障碍 |
|---|---|
| 事出有因 | 心境抑郁（可无诱因） |
| 有一定时限 | 丧失兴趣和愉悦感 |
| 可自我调试或自行缓解 | 明显心理痛苦感 |
| 对生活工作负面影响小 | 社会功能受损，**至少连续 2 周** |

**DSM-5 重性抑郁发作（节选）**
A. 至少连续 **2 周**，出现 **≥5** 条下列症状，且至少 1 项是①或②：
① 心境抑郁 ② 丧失兴趣和愉悦感 ③ 体重明显减轻或增加 ④ 失眠或睡眠过多
⑤ 精神运动性激越或迟滞 ⑥ 疲劳或精力不足 ⑦ 毫无价值感、过分内疚
⑧ 注意力不集中或犹豫不决 ⑨ 反复出现死亡想法、自杀意念、自杀企图或计划
B. 有临床意义的痛苦，或社交、职业等重要功能损害
C. 不能归因于物质或躯体疾病
D. 不能用其他精神障碍更好解释
E. 从无躁狂/轻躁狂发作

**我国抑郁症"三高三低"**：高发病率、高复发率、高自杀率；低知晓率、低就诊率、低治疗率。

**应对**：药物（中重度）、心理治疗/咨询（轻度）、药物+心理（中重度）、社会支持（辅导员、班主任、同学）、自助（运动、心理自助书籍、正念冥想）。

### 3.2 焦虑障碍
**焦虑情绪 vs 焦虑障碍**：焦虑障碍 = 焦虑的情绪体验 + 身体表现 + **≥6 个月** + 引起痛苦或社交/学业/职业功能损害。

| 类型 | 要点 |
|---|---|
| 广泛性焦虑障碍 | 对很多主题/任务/事件严重担忧，难以控制，坐立不安、紧张、注意力难集中、易激惹 |
| 惊恐障碍 | 急性发作，强烈濒死感、失控感、人格解体；反复心悸、震颤、头晕等植物神经症状 |
| 社交焦虑障碍 | 对社交场合或人前表现有显著持续担忧/恐惧，**≥6 个月**，主动回避，明显痛苦 |

**应对**：放松训练（肌肉放松、想象放松、瑜伽）；参与愉快活动与锻炼；识别并挑战"糟糕至极、绝对化、过分概括化"的负性认知；心理科就诊、药物治疗；心理咨询。

### 3.3 强迫障碍
- **强迫倾向**：不影响正常学习工作社交的轻微症状，不算病态。
- **强迫障碍**：以强迫思维、强迫行为为主要表现，重复、耗时、引起痛苦，极大困扰学习生活，可导致焦虑抑郁。
- 核心：强迫思维（联想、回忆、疑虑、穷思竭虑、对立思维）+ 强迫行为（洗涤、检查、计数、仪式动作）；**强迫与反强迫**；**有自知力但无法摆脱**，因而痛苦。
- 应对：顺应自然的生活观、森田疗法、药物、心理咨询。

### 3.4 双相情感障碍
= 抑郁发作 + 躁狂发作。

**躁狂发作（DSM-5 节选）**
A. 持续 **≥1 周**（或短于此但达到必须住院程度）的异常、持续的心境高涨、夸大或易激惹，或活动增多、精力旺盛
B. 期间至少符合 **3 项**：① 自尊膨胀或夸大 ② 睡眠需求减少（如 3 小时即觉够）③ 比平时更健谈/有持续讲话压力 ④ 意念飘忽/思维奔逸 ⑤ 随境转移 ⑥ 有目标的活动增多或精神运动性激越 ⑦ 过度参与高风险活动（无节制购物、轻率性行为、愚蠢投资）
C. 严重到显著损害社交或职业功能

**应对**：鼓励就医（药物/住院）；从对方角度考虑；不当面发泄怒气、不反击；耐心陪伴与监控，防过激事件；及时寻求专业帮助。

### 3.5 精神分裂症
- 以精神活动不协调、脱离现实为特征。
- **阳性症状**：幻觉、妄想、思维（言语）紊乱、明显紊乱或异常的运动行为
- **阴性症状**：情感淡漠、意志减退、思维贫乏、快感缺失、社会退缩
- **诊断核心**：≥2 项症状持续 1 个月显著存在，且至少 1 项为妄想/幻觉/言语紊乱；功能显著低于病前；**病程 ≥6 个月**；排除物质与躯体疾病。
- **应对**：已丧失自知力 → **保证当事人及周围人安全是首要**，指派专人 24 小时看守；院系联系家长（就医须家长签字，或公安强制送医）；尽早、及时、系统、正规送医；理解关怀、不歧视。

### 3.6 适应障碍（常被漏掉的鉴别）
- 明确的应激源（失恋、转学、退学、家庭变故、重大疾病）后 **1–3 个月内**出现情绪或行为症状
- 症状**未达到**其他精神障碍（如抑郁发作、焦虑障碍）的完整诊断标准
- 应激源消除后症状多在 **6 个月内**缓解
- **性质上是排除性诊断**：只要满足抑郁/焦虑发作的条目，就优先下后者
- 答题用法：写"需与适应障碍鉴别——症状是否严格继发于应激事件、且未达抑郁发作的条目要求"

## 四、心理危机

### 4.1 定义与三标准
心理危机：个体面临**突然或重大的负性生活事件**时，既不能回避，又无法用通常解决问题的方法来解决时所出现的**心理失控状态**。

三标准：
1. **挑战**：对当事人是不寻常、有挑战性的事件
2. **困境**：可能让人陷入困境，带来明显心理困扰
3. **无效**：当事人常见的应对机制失效

（另有表述：存在负性事件 + 依靠自身能力应对无效 + 有明显躯体和心理不适感）

### 4.2 危机中的身心反应
| 层面 | 表现 |
|---|---|
| 生理 | 疲劳、胸闷、眩晕、失眠或嗜睡、厌食或暴食、胃痛 |
| 认知 | 注意不集中、记忆下降、难以决策、不断想到诱发因素 |
| 情绪 | 焦虑-恐惧、不满-愤怒、无助-绝望、情绪失调 |
| 行为 | 挑衅-攻击、坐立不安、退缩-逃避、过度工作、哭泣呆坐、酒精或药物使用 |

损害程度可分**少许 / 中度 / 严重**三档（严重：情绪与环境极不匹配、认知完全脱离现实、行为不可控且有破坏性）。

### 4.3 危机类型
1. **发展性危机**：人生发展急剧变化所致。不上课不外出、失去兴趣；专业满意度低无动力；沉迷游戏网络；成绩骤降挂科退学；长期独来独往；表白被拒、恋情结束。
2. **境遇性危机**：不可预测、不可控的危及生存事件。自然灾害、意外伤害、突发重大疾病、亲人突然过世、性骚扰/性侵害、诈骗、家庭经济破产。特点：随机、突发、灾难性，个体感到失控、不安全。
3. **存在性危机**：伴随重要人生问题的内部冲突与焦虑。对自我要求极高、过度完美主义；关注暗黑/自杀内容；突然对宗教哲学心理学浓厚兴趣；**觉得人生无意义、觉得自己是他人的拖累、过度自责羞愧**。
4. **病理性危机**：由精神障碍导致。精神分裂症、双相、抑郁、严重焦虑、边缘人格障碍、厌食症。

### 4.4 危机发展四阶段（Caplan）
警觉阶段 → 功能恶化阶段 → 求助阶段 → （成长阶段 / 危机阶段）
- 应对有效：复原、危机后成长
- 应对无效：幸存但有损伤、可能有危机状态转移、崩溃

**危机 = 危险 + 机遇**（祸兮福所倚）。

### 4.5 危机信号（高风险指标）
- **言语**：直接、间接、委婉暗示想死（朋友圈、微博、论坛）
- **行为**：与平时不同，无缘无故收拾东西；向人道谢、告别、归还物品、赠送纪念品；把珍贵的东西送人；有条理地安排后事
- **处境**：频繁出现意外事故；过分孤独、回避与人接触、与集体不融洽
- **情绪**：无望、敌意、绝望，关注暴力主题

**伤人危机预兆**：强烈不甘心不服气不公平；愤怒甚至想激烈报复；无故愤怒或敌意、肢体暴力；暗示或直接威胁自己或他人；跟踪或骚扰。**伤人风险中一般同时蕴含自杀风险。**

**自杀三阶段**：纠结的自杀倾向期 → 有一定计划的呼救期 → **平静的行为实施期（风险最大）**。
**注意**：长时间痛苦挣扎之后的**平静**往往风险更大。有自杀未遂史者风险更高。

### 4.6 危机干预总原则
- 危机发生**前**：识别和预防
- 危机发生**中**：干预和处理
- 危机发生**后**：疏导和善后
- 危机干预是**短程**帮助过程，是"情绪急救"；朋辈主要做**识别与转介**，不能胜任时及时求助专业人员。

### 4.7 帮扶重心（马斯洛需要层次）
```
自我实现
自尊（价值—成就—责任）      ← 多数错误的危机处理从此开始（灌输价值感、勉强表扬）
爱与归属（家人、朋友、老师）  ← 多数危机处理在此阶段结束
安全（身体与心理、信任）      ← 危机干预从这里开始
生理（物质方式满足）          ← 温暖与吃喝、安全
```
危机个体常觉得"没有价值、低成就感、没有希望"，但对方此刻最缺的是**安全与联结**，不是道理。

### 4.8 朋辈帮扶策略（发现危机线索时）
1. 找一个稳定的时间和空间私下安全谈话
2. 表达关心，真诚地**直接询问**是否有自杀想法；痛苦难以承受时有自杀想法是正常的（**询问不会诱导自杀，反而能拯救生命**）
3. 多听少说，保持冷静耐心，让对方倾诉
4. 尊重感受，避免直接分析或判断；语言不能缓解痛苦
5. 相信对方的话、认真对待；**若要求对自杀想法保密，不要答应**，及时求助（**自杀风险保密例外**）
6. 注意：住院稳妥之前**不要让其独处**；刚出现自杀行为的，立即送最近急诊室抢救，抢救回来后送专科医院住院

### 4.9 向谁报告
1. 思政工作队伍：辅导员、学院领导、保卫处
2. 专业机构：心理中心、校医院、110
注意事项：重视风险、毋存侥幸；尽力保持现场人员与环境安全稳定；报告人自身保持稳定、清楚描述事件。

## 五、朋辈心理辅导伦理

### 5.1 五大总则（《中国心理学会临床与咨询心理学工作伦理守则》第二版）
| 原则 | 内涵 |
|---|---|
| **善行** | 使求助者获益、保障权利、得到适当服务、避免伤害 |
| **责任** | 保持服务水准；认清伦理与法律责任；维护信誉；**在自身胜任力范围内**为适宜人群服务 |
| **诚信** | 诚实守信；求助者有权充分了解辅导过程与辅导者资质（知情同意，不欺骗不夸大） |
| **公正** | 公平公正；谨慎防止自身偏见、能力局限、技术限制导致的不当行为（中立、多重关系处理） |
| **尊重** | 尊重隐私权、保密性与自我决定的权利；不能替别人做决定；**生命高于一切** |

### 5.2 工作范围（责任的边界）
- 健康心理：自我探索、压力下保持良好状态
- 一般心理问题：如失恋的正常反应 → **陪伴、疏导**
- 严重心理问题：无法自我调整、事件泛化 → **建议心理咨询**
- 精神障碍：郁郁寡欢、无法正常行为、无自知力 → **精神科就诊**

### 5.3 保密与保密例外
保密原则的例外（三条）：
1. 发现求助者有**伤害自身或他人的严重危险**
2. 不具备完全民事行为能力的未成年人等**受到性侵犯或虐待**
3. 法律规定需要披露的其他情况

**有限内容、有限范围**：只按最低限度原则披露必要信息；告知对方披露的范围与理由。
《精神卫生法》第二十八条：疑似精神障碍患者发生伤害自身、危害他人安全的行为，或有此危险的，其近亲属、所在单位、当地公安机关应当立即采取措施予以制止，并送医疗机构诊断。

### 5.4 多重关系
清楚了解多重关系（家庭、社交、经济、商业或其他密切个人关系）对判断的不利影响及对求助者福祉的潜在危险，**尽可能避免**；不可避免时采取专业措施预防（告知风险、签署知情同意、寻求督导、做好记录），确保不影响判断、不造成危害。
- 不得与当前求助者及其家庭成员发生任何形式的性或亲密关系
- 结束咨询关系后**至少三年内**亦不得

### 5.5 伦理决策七步
1. 界定问题（明确困境是什么）
2. 辨识受决策影响的参与者
3. 辨识各参与者可能采取的行动及潜在利益与风险
4. 评估各行动方案的利益与风险
5. 与同事和专家商讨
6. 决定实施最可行的备选方案，记录决策过程
7. 实施、评估、记录已做出的决策

## 六、朋辈个体辅导

### 6.1 谈话 vs 聊天
| 维度 | 聊天 | 谈话 |
|---|---|---|
| 目的性 | 即兴、随意、方向不明 | 相对专业且系统，有目标 |
| 角色 | 无角色划分，不承担职责 | 朋辈辅导者 vs 求助者，承担责任 |
| 技术 | 凭心情、性格、自我经验 | 经专业训练，把控内容与进度 |
| 评估 | 无需评估反思 | 记录、总结、反思、必要时督导 |

**无效谈话的四个特征**：以"你"开头（命令口气）；以偏概全（总是、从不、每次）；由事及人；无视情感。

### 6.2 五大基本理念
1. **尊重**：在价值、尊严、人格上保持平等；无条件尊重（了解其价值体系、中性接纳包括灰暗错误的一面、保护隐私、勿评价和过度询问）；无法接纳则主动转介。
2. **温暖**（≠热情）：温和倾听、表情适当、耐心接纳。过于热情显得强势。
3. **真诚**（≠全部说真话）：真实诚恳、实事求是、适度；不是自我发泄。
4. **共情**（≠同情）：体验对方内心世界的能力（Rogers）。
   - 步骤：识别情绪并尝试交流 → 接纳对方观点 → 一起感受 → **不评论、不分析原因**
   - 比喻：同情是站在坑边问"你还好吗"；共情是爬下坑说"原来待在这里是这样的感受，我们一起想想怎么上去"。
5. **积极关注**：关注言语行为中积极光明的方面，帮助建立正向价值观，产生改变动力；用客观语言表达积极态度，寻找正向优势。朋辈对同学更熟悉，天然拥有"积极关注"的资源库。

### 6.3 身体语言 SOLER（Egan, 1994）
Squarely 正面朝向 · Open 开放体态 · Lean 身体微倾 · Eye 良好目光接触 · Relax 放松
（前提：安全舒适的环境）
非言语沟通在信息传递效果中占 **55%**（文字 7%，声音 38%）。沟通方式优先级：面对面 > 视频 > 语音 > 文字。

### 6.4 朋辈辅导过程（六步）
1. **准备**：为什么谈、谈什么、列提纲；时间双方有空；地点安全不被打扰；温暖开场
2. **倾听与建立关系**：用耳、用眼、用心；表情温和、语速适中；以听为主、轻微鼓励；保持好奇与中立、不臆断；不急于分享经验（"我曾经"）；允许沉默
3. **探索想法与感受**：开放式提问（"可不可以举个例子""想到……你会浮现什么想法/感受"）；封闭式提问用于澄清事实、缩小范围；**先重述再开放提问**更自然
4. **解决问题：先情感，后建议**（核心）；可用非暴力沟通
5. **探索资源与优势**：内在性格品质；动机与行动（好学、努力、态度）；支持性关系（家人、老师、朋友）；过往成功体验；外在健康形象；精神层面（三观健康）
6. **结束**：概述主要内容 → 肯定做得好的部分 → 建议与指导（适度，可建议心理咨询）→ 表达鼓励与感谢 → 约定下次

### 6.5 非暴力沟通四步（马歇尔·卢森堡）
1. **观察**，而非评论——具体客观描述事实
2. **感受**，而非想法——用具体情绪语言
3. **需要**，而非批评——直接说出心理需要
4. **请求**，而非命令——清晰具体的行动建议
人际沟通三元素：自我（自己的感受与需要）、他人（他人的感受与需要）、情境（在情境中调整）。

### 6.6 优势视角
- 理论基础：以人为中心治疗（Rogers）、社会工作优势视角（Saleebey）、积极心理治疗（Seligman）
- 理念转变：从聚焦"坏事/局限"到聚焦"好事/优势"；从"受害者模式"到"获益者模式"
- 发现自我优势的方法：自我经验总结、邀请他人反馈、性格优势测试（VIA）
- **运用要点**：优势要放到匹配的领域；对严重抑郁者不要要求"回忆辉煌"，改为从小目标、具体行为入手

## 六·附 · 具体调节技术（带剂量，写建议时可直接引用）

**运动**
- 机制：分泌内啡肽，释放压抑情绪，改善血氧；心理上增加幸福感、减少失眠、提高注意记忆、减少抑郁
- 处方：每周 **4~5 次**，每次 **20~30 分钟**，心率控制在 **(220−年龄)×0.75**
- 方式：跑步、游泳、骑自行车、健走（先评估身体状况）

**渐进式肌肉放松（PMR）**
- 每组肌群收缩 **10 秒**后松开，放松 **15~20 秒**
- 顺序：优势手/前臂/肱二头肌 → 非优势侧 → 前额 → 眼 → 颈咽部（双臂前伸、后展、耸肩）→ 肩背 → 胸 → 腹 → 臀 → 大腿 → 小腿（脚尖上/下）→ 脚（内收外展）

**腹式呼吸**
- 吸气时腹部逐渐充盈；每天 **2 次**，每次 **5 分钟**，至少坚持 **2 周**

**引导式内观 / 冥想 / 正念**
- 内观：用心理意象改变行为方式、感知方式与生理状态，想象身处平静情境
- 正念：有目的、有意识地觉察当下，**不作判断、不作分析、不作反应**，只是单纯觉察

**三条非理性信念（Ellis, REBT）与调整**
| 类型 | 标志性用词 | 调整方向 |
|---|---|---|
| 绝对化要求 | 必须、应该、务必、完全、绝对；非黑即白 | 用概率、一定程度、分部分来看 |
| 过分概括化 | 总是、永远、每次 | 具体量化，客观描述具体压力 |
| 糟糕至极 | 太恐怖了、要多坏有多坏、末日 | 相信身心承受力；改变可改变之事，接受不可改变之事 |

另两种认知偏差：**自我实现预言**（越担心越出现→关注解决办法）、**个人化/焦点效应**（→放弃揣测、适度验证）。

**三类应对策略与效果**
- 回避策略：有时短期缓解；**长期无效**
- 情绪中心策略：减轻消极情绪；使用者焦虑水平**更低**
- 问题中心策略：直接处理压力源
- 结论：**积极策略（问题中心/情绪中心）都比回避更有效**；不可答成"回避完全无效"

**压力—效率倒 U 曲线**：适度压力是推动力，过度压力损害身心与效率。

**四类社会支持**（James & Gilliland, 2013）：后勤支持、信息支持、心理支持、社会支持。

## 九、可直接引用的理论句

- **压力—易感模型**：几乎每个人在压力大到一定程度后出现心理障碍表现都是正常的；此时不论是谁，寻求专业帮助都是必要的。
- **危机 = 危险 + 机遇**："祸兮福所倚，福兮祸所伏"。
- **心理危机正常化**：危机是个体面对突发事件时的正常心理反应；程度取决于个体对事件的感受和解释，而非事件本身；危机是暂时性的。
- **马斯洛需要层次**：危机干预从安全与生理需要开始，而非从"灌输价值感"开始。
- **优势视角**："几乎所有的事情在某种特定条件下都可以视为一种优势"（Saleebey, 1996）。
- **助人自助**：在互惠努力的情境下，帮助他人实际上也帮助了自己。
- **艾里克森**：成年早期（18–25 岁）的主要发展任务是获得亲密感、避免孤独感。
- **心理健康素养四维**（江光荣等，2020）：自己/他人 × 心理健康维护促进/心理疾病识别应对。
- **去污名化**：社会污名与病耻感会使人因害怕歧视而不敢求助，贻误咨询治疗，使问题恶化。
