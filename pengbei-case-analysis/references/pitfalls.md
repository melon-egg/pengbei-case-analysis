# 扣分点与"AI 味"陷阱

> 来源：课程老师对一份 AI 生成答案的逐条批注（`案例分析参考资料/作答.docx`）+ 常见答题失误。
> **输出前扫一遍，逐条确认没有踩中。**

---

## 一、老师明确批过的三条（最容易被扣分）

### 1. 询问自杀像"完成检查清单"
> 原批注：AI 建议"温和但直接地询问其心理状况"，虽然正确且必要，但**如果问得过于生硬、像在完成检查清单，可能会让对方感到被审问，从而关闭心扉**。

**改法**：先铺垫关心 → 再用**日常口语**问 → 给对方留退路 → 不连珠炮连问四个问题。
- ❌ "你有没有自杀计划？有没有手段？有没有既往史？"
- ✅ "你刚才说想快点结束生命……这句话我听到了，也很在意。是偶尔会闪过，还是已经认真想过要怎么做？"

### 2. 过度介入，削弱自主性
> 原批注：AI 建议"主动提出陪同前往"，**过度介入可能让对方感到压力或依赖，削弱她的自主性**。应重在陪伴而非替代，更可行的是提供资源信息后，由她自行决定。

**改法**：默认写"**提供信息 + 邀请 + 尊重决定**"；只在**情况紧急**时写"务必陪同"。
- ❌ "主动陪同她去心理咨询中心。"
- ✅ "告知预约方式并询问'需要我陪你去吗'，尊重她的选择；若出现紧急危险则陪同前往。"

### 3. 优势视角空洞、反而加重无力感
> 原批注：AI 对"发掘优势"的描述较笼统，如"引导她回顾过去成功的经历"，但**未考虑严重抑郁者当前难以聚焦积极回忆**，且**回忆过去的辉煌会加重当下的无力感**，加剧抑郁焦虑；**宜从小目标入手（如完成一次作业），而非要求反思**。

**改法**：优势要从**当下的小事**切入，不给"反思作业"。
- ❌ "引导她回顾过去成功的经历，重建自信。"
- ✅ "从今天做到的一件小事入手肯定她（'你今天来上课了，这很不容易'），再一起定一个明天就能完成的小目标。"

## 二、内容层面的高频失分

| 失分点 | 表现 | 修正 |
|---|---|---|
| **漏自杀风险** | 案例里写了"不想活""结束生命"却不提 | 只要有一丝线索，风险第一条必须写，并写保密例外 |
| **下诊断** | "她得了重度抑郁症" | "符合抑郁发作特征，需专业评估" |
| **只写心理不写躯体** | 忽略体重、睡眠、进食 | 生理维度单列一条 |
| **不引用案例** | 全是通用术语 | 每条后加括号引原话或数据 |
| **帮助措施空泛** | "多关心她""多陪伴""让她想开点" | 落到"谁、做什么、怎么做、多久" |
| **无边界** | 全程像心理咨询师 | 明写"朋辈不诊断、不治疗、不替代" |
| **无资源** | 只说"建议求助" | 至少写 2 个具体资源（心理中心、校医院心理门诊、12356/96525） |
| **不分主次** | 六条风险平铺 | 自杀风险排第一并标注"首要" |
| **答非所问** | 题干问"风险因素"，答成"帮助措施" | 严格按小问分节，标题与题干同词 |
| **漏保护因素** | 只列危险 | 加一句保护因素（牵挂家人、求助意愿、既往应对经验） |

## 三、语言层面的"AI 味"

- ❌ 开头："这是一个非常典型的案例，让我们一起来分析……"
- ❌ 结尾："希望这些建议对你有所帮助！"
- ❌ 元话语："根据朋辈心理辅导的理论……"（堆在段首）
- ❌ 过度排比、形容词堆砌："深深的孤独、无尽的痛苦、难以言说的绝望"
- ❌ 每点都用"首先/其次/再次/最后"四段式，像作文
- ✅ 正确：直接给判断，加粗小标题，短句，术语 + 案例依据。

## 四、"看起来对但其实错"的表述

| 说法 | 问题 |
|---|---|
| "有自杀想法的人不会说出来，说出来只是求关注" | 错。**直接询问不会诱导自杀，反而能救命**；要相信并认真对待 |
| "答应替她保密，这样她才信任我" | 错。自杀风险属**保密例外**，不能承诺 |
| "让她多参加集体活动就好了" | 对严重抑郁者是负担；应改为**低压力、可拒绝**的陪伴式活动 |
| "抑郁就是想不开，劝劝就好" | 错。抑郁有生物学基础，中重度需药物 + 心理治疗 |
| "回避策略完全没用" | 错。**短期**可缓解，长期无效；积极策略更有效 |
| "朋辈可以初步诊断，方便转介" | 错。朋辈**不做诊断**，只做识别与转介 |
| "她只是失恋，属于正常反应，不用管" | 正常反应也需关注；若出现自伤/报复念头须升级处理 |
| "马上带她去医院，越快越好，不用问她" | 除紧急情况外应尊重自主；强行带去会破坏信任 |

## 五、最后 30 秒检查

1. 每一问都有小标题，且用题干原词？
2. 自杀风险在"风险"第一条？
3. 有"保密例外"四个字？
4. 有"转介"和至少两个具体资源？
5. 有"朋辈不诊断/不替代"的边界句？
6. 每条判断后面有案例依据？
7. 没有"想开点/别想太多/多参加活动"？
8. 字数在 800–1200？
