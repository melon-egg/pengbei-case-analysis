# 案例类型路由器

> 用法：读完案例，先归类，再套用对应一节的"信号 → 判断 → 风险 → 帮助 → 陷阱"。
> 绝大多数考题是 1+2 或 1+4 的组合（抑郁 + 自杀风险 / 学业 + 抑郁）。

---

## 类型 1 · 抑郁与自杀风险型（最高频，必须练熟）

**识别信号**
- 情绪：持续心境低落、想哭、兴趣与愉悦感丧失、"笑不出来"
- 认知：自我否定、无价值感、过分内疚、注意与记忆下降、犹豫不决
- 生理：入睡困难、**早醒且不能再入睡**、食欲下降、体重明显下降、疲劳、晨起困难
- 行为：社交退缩、成绩下滑、独来独往、活动减少
- 危险认知："我是累赘""活着没有意义""对不起父母"

**判断**
- 数条数：≥5 条且含①心境抑郁或②兴趣丧失 + ≥2 周 + 功能损害 → **高度提示抑郁发作**
- 三条判断标准同时满足 → 精神障碍层级，超出朋辈范围
- 措辞："符合……特征，需专业评估"，不诊断

**风险（至少写 5 条）**
1. 自杀风险（意念/计划/手段/既往史/无望/累赘感/孤立）
2. 病情恶化（病程长、条目多、持续下降）
3. 躯体（进食、体重、失眠）
4. 学业滑坡 → 二次打击 → 恶性循环
5. 社会支持薄弱 + 对家人报喜不报忧 + 病耻感
6. 保密例外风险

**帮助**
- 立即评估自杀风险 → 不承诺保密 → 上报 → 24h 陪伴 → 危险物品管理
- 转介心理中心/校医院心理门诊/精神科，解释生物学基础，去污名
- 朋辈持续：小目标行为激活、低压力社交、共情倾听、优势视角（小成功）
- 边界：不诊断、不治疗、不替代

**陷阱**
- 只说"多陪伴多关心"——空
- 把"对不起父母"只当自责，没看出**累赘感 = 高危认知**
- 忽略早醒（抑郁严重度的重要指标）
- 忘记保密例外
- 建议"多参加集体活动"——对严重抑郁者是负担

## 类型 2 · 焦虑 / 考试焦虑型

**信号**：考前心慌、颤抖、失眠、坐立不安、注意力难集中、反复担心考不好、灾难化（"考不好就完了"）、回避复习

**判断**：焦虑情绪（事出有因、有时限、功能影响小）vs 焦虑障碍（≥6 个月、痛苦、功能损害）。多数校园案例属**一般心理问题**。

**风险**：考试失利 → 自我否定；回避 → 恶性循环；失眠 → 躯体；若合并抑郁需警惕；极端时可能出现自伤

**帮助**
- 正常化："考前紧张是正常的，适度焦虑有助于发挥"
- 放松训练：腹式呼吸、渐进式肌肉放松、想象放松
- 认知：识别"糟糕至极、绝对化、过分概括化"，做证据检验
- 行为：拆解复习计划、番茄钟、减少熬夜、运动
- 资源：学业指导、学长经验、心理中心
- 若 ≥6 个月且功能明显受损 → 建议心理咨询/心理科

**陷阱**：一上来讲大道理；忽视躯体症状；把正常焦虑病理化

---

## 类型 3 · 学业适应 / 挂科 / 拖延型

**信号**：成绩下滑、挂科、逃课、拖延、无学习动力、自我效能感低、"再怎么努力也比不上别人"

**判断**：多为**发展性危机 / 一般心理问题**；注意是否已泛化、是否合并抑郁

**风险**：学业警告/退学；自我价值崩塌；沉迷游戏网络；社交退缩；若出现"活着好累"类表达立即升级为危机

**帮助**
- 倾听理解，先处理情绪再处理问题
- 探索学习目标与动力（喜欢的方向、意义感）
- 关注其过往优势，一起探索可尝试的方法策略
- 协助订立**科学可行**的学习计划（学习类 APP、学习搭子、云同桌）
- 分享减压技巧并带着练
- 连接资源：学业指导中心、辅导员、任课老师、学长、心理中心
- 生涯迷茫 → 职业规划课程、就业中心、社会实践

**陷阱**：只谈学习方法不谈情绪；用"你要努力"施压；忽略挂科背后的自我否定

## 类型 4 · 人际 / 宿舍 / 社交焦虑型

**信号**：宿舍冲突、被孤立、不敢社交、眼神躲闪、担心被看不起、独来独往、内心孤独、过度在意他人评价

**判断**：一般心理问题为主；若回避持续 ≥6 个月且显著痛苦 → 考虑社交焦虑障碍

**风险**：社会支持持续减少；宿舍矛盾激化；被欺凌；继发抑郁

**帮助**
- 先纾解情绪，**不急于给建议**
- 澄清其惯有的沟通模式，提升自我觉察
- 用非暴力沟通做表达演练（观察—感受—需要—请求）
- 真诚反馈你对其的积极观感，帮助悦纳自我
- 鼓励（非强迫）参与线下校园活动；建议参加人际主题团辅
- 必要时协助与室友/辅导员沟通，但不做"传话筒"、不站队

**陷阱**：替对方出头；评判谁对谁错；建议"你就大胆一点"

---

## 类型 5 · 恋爱 / 分手型

**信号**：失恋后反复自省、自我贬低、叹气、情绪低落、回避集体活动、失眠、无心学习；或恋爱中的患得患失

**判断**：多为**一般心理问题 / 发展性危机**；失恋的正常反应属健康心理范畴的应激

**风险**：自我价值感受损；社交退缩；学业下滑；**饮酒与冲动**（摔东西、争吵）→ 自伤或伤人的门槛降低；极端情况下的报复风险（尤其被背叛、公开羞辱、纠缠期）

**帮助**
- 共情接纳，不评判、不劝"忘了吧"
- 允许悲伤，正常化
- 探索其在关系中的需要与模式，而非评价对方
- 优势视角：从具体的小胜任感入手
- 恢复作息与社交节奏；鼓励运动；**减少饮酒**（酒精会放大冲动与低落，属非适应性应对）
- 对方难以抉择时**不要给明确建议**，引导其想象不同选择的最好与最坏结果
- 与异性同学谈话注意边界，避免误会
- 若出现"没人在乎""活着没意思"等表达，立即按**类型 1** 的危机流程处理

**陷阱**：站队骂对方；催促"赶紧走出来"；给出"分/不分"的结论

---

## 类型 6 · 双相 / 躁狂型

**信号**：一段时间精力旺盛、睡得少却不累、话多、思维奔逸、花钱大手大脚、目标宏大、夸大；随后突然跌入抑郁（情绪低落、不起床、暴瘦、缺考）

**判断**：躁狂 ≥1 周 + ≥3 条 + 功能损害 → 高度提示双相，**必须精神科就诊**

**风险**：冲动行为（过度消费、危险驾驶、轻率性行为）；躁狂期自伤他伤；抑郁期自杀；学业中断

**帮助**
- 鼓励并协助就医（药物/住院），不与其争辩夸大观念
- 从对方角度考虑；不当面发泄怒气、不反击
- 耐心陪伴与监控，防止过激事件
- 及时寻求专业人员帮助；通知辅导员与家长
- 抑郁相出现时按抑郁+自杀风险处理

**陷阱**：把躁狂期的"积极"当成好转；只处理抑郁相而漏掉躁狂史

## 类型 7 · 精神分裂症 / 幻觉妄想型

**信号**：听见别人听不到的声音、坚信被监视/被议论、言语离题不连贯、行为紊乱、情感淡漠、生活疏懒、个人卫生差、半年内功能显著下降

**判断**：≥2 项核心症状 + ≥6 个月 + 功能显著低于病前 → 高度提示精神病性障碍

**风险**：**丧失自知力 → 自伤他伤风险高**；走失；被害妄想导致的防卫性攻击；延误治疗致预后变差

**帮助**
- **安全第一**：保证当事人及周围人安全，安排专人 24 小时看护
- 立即报告辅导员/学院/家长/心理中心；就医须家长签字（或公安强制送医）
- 尽早、及时、系统、正规送医
- 理解、关怀、帮助，不歧视、不厌恶、不冷淡
- 不与其争辩幻觉妄想内容，不附和，也不否定，转向现实与安全

**陷阱**：试图"讲道理"说服；单独处理；拖延上报

## 类型 8 · 危机事件型（丧失、创伤、重大挫折）

**信号**：亲人去世、重大疾病、遭遇性侵/骚扰、被骗、家庭变故、公开羞辱、考试失利后的崩溃；伴随震惊、麻木、哭泣、失眠、无法上课、说"活着好累"

**判断**：负性事件 + 常规应对失效 + 无助无望失控 → **心理危机**（境遇性/发展性）

**风险**：急性应激反应；自杀风险陡增（尤其丧失后 1 个月内）；创伤后应激；社会功能全面停摆

**帮助**
- **正常化**："遇到这件事，允许自己有这些反应，是人之常情"
- 主动识别、主动关心，不回避话题
- 提供四类支持：后勤（吃住行）、信息（资源与流程）、心理（倾听陪伴）、社会（联结他人）
- 评估自杀风险；必要时启动保密例外
- 转介心理中心/专科；性侵等涉及法律情形按法律规定处理（保密例外）
- 不催促"走出来"，尊重节奏

**陷阱**：说"节哀""想开点"；过早给建议；忽略法律与报告义务

## 类型 9 · 伦理两难型

**常见情境**：来访者要求保密但存在自杀风险；与来访者产生好感；来访者是熟人/室友；自身耗竭想拒绝又内疚。

**走法**：界定问题 → 参与者 → 备选方案及利弊 → 评估 → 与同事专家商讨 → 决定并记录 → 实施评估记录。

**标准结论句式**
> 生命高于一切。当存在伤害自身或他人的严重危险时，保密义务让位于安全义务；应采用**有限内容、有限范围**的披露，只告知必须知情的人，并向当事人说明披露的范围与理由，同时保持陪伴与支持。

**陷阱**：答应保密；全盘公开；因"朋友关系"模糊边界；独自承担
