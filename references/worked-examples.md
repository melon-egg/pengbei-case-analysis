## 例 1 · 历年真题「小A」（抑郁 + 自杀风险型）

> **题干**：小A，大二女生，近三个月以来一直情绪低落、想哭。过去喜欢的电影、美食再也提不起兴趣。同学聚会能推就推，感觉"笑不出来了"。持续感到极度疲劳。早上起床变得异常困难。学习注意力无法集中，记忆力下降，学习成绩直线下滑。胃口不好，不太有食欲，有时候一天只吃一顿饭，体重轻了7斤。睡眠质量也很差，入睡困难，躺在床上要1-2小时才能睡着，且容易早醒，醒来后再也无法入睡。不擅长与人交往，很难融入集体生活中，经常独自一个人，感到孤独和失落。她经常自责，感到自己很没用，对不起父母家人，认为自己活着就是父母的累赘，无数次想快点结束自己的生命。
>
> 请结合朋辈心理辅导的识别与帮扶知识要点回答：小A可能存在什么问题？需要注意哪些风险因素？可以做些什么去帮助小A？

---

### 一、小A 可能存在什么问题

**总体判断**：小A 的症状条目多、持续近三个月、社会功能明显受损，已超出"一般心理问题"的范畴，**高度提示抑郁发作**，并伴反复自杀意念，属于**精神障碍合并心理危机**的层级，**需立即转介专业评估**。朋辈不作诊断，最终结论应由精神科医生作出。

1. **情绪问题**：持续心境低落、想哭，"过去喜欢的电影、美食再也提不起兴趣"（兴趣与愉悦感丧失），"笑不出来了"，符合抑郁发作的两项核心症状。
2. **认知问题**：自我否定与无价值感（"感到自己很没用"）、过分内疚（"对不起父母家人"）、**累赘感**（"自己活着就是父母的累赘"）、注意力无法集中与记忆力下降，构成典型的抑郁性认知模式。
3. **生理/躯体问题**：入睡困难（需 1–2 小时）、**早醒且醒后无法再入睡**、食欲下降（一天只吃一顿）、三个月体重下降 7 斤、持续疲劳与晨起困难。早醒与体重显著下降提示程度较重。
4. **行为与社会功能问题**：社交退缩（"同学聚会能推就推""经常独自一个人"）、学业功能受损（"学习成绩直线下滑"）、生活节律紊乱。社会功能已出现明显损害。
5. **发展性议题**：大二正处于自我认同与亲密关系建立的关键期，长期孤立使其"爱与归属"的需要得不到满足，进一步加剧孤独与无望。

> 依据 DSM-5，小A 已具备心境抑郁、兴趣丧失、体重下降、失眠（早醒）、疲劳、注意力不集中、无价值感与内疚、反复自杀意念等 **8 项以上**症状，且持续远超 2 周，社会功能受损明显，**符合重性抑郁发作的条目要求**。

---

### 二、需要注意哪些风险因素

**风险等级：高。** 反复自杀意念 + 多项高危认知 + 社会支持薄弱，须立即启动风险评估与保密例外程序。

1. **自杀风险（首要）**：小A"无数次想快点结束自己的生命"，属反复出现的自杀意念；同时具备**无望感、无价值感、累赘感、社交孤立、早醒**等多项高危因素。"自己活着就是父母的累赘"是典型的存在性危机表述，是极高的危险信号。需进一步评估：意念的**频率与强度**、**有无具体计划**、**手段是否可得**、**既往有无自伤或自杀尝试**（有未遂史者风险显著升高）。
2. **病情恶化风险**：症状持续近三个月未缓解，多项核心症状并存，若不干预可能进一步加重，出现冲动性自伤或自杀行为。
3. **躯体健康风险**：长期进食过少、体重下降 7 斤、持续失眠，可能导致营养不良、免疫力下降及躯体疾病。
4. **学业与社会功能风险**：注意力与记忆力下降导致成绩下滑，可能引发挂科、学业警告，形成"成绩差—自我否定—更学不进去"的恶性循环，进一步削弱自我价值感。
5. **社会支持与求助障碍**：社交退缩、独来独往使支持系统薄弱；对父母强烈的内疚可能使其"报喜不报忧"；对精神疾病的病耻感可能阻碍其主动求助。
6. **伦理与保密风险**：若小A 要求对自杀想法保密，属于**保密例外**情形，朋辈不得承诺保密，须在有限内容、有限范围内及时报告。

> 保护因素：她对父母的牵挂与责任感、主动向人表达痛苦（说明仍有求助意愿），都可以作为工作的切入点。

---

### 三、可以做些什么去帮助小A

朋辈的角色是**识别、陪伴与转介**，不是诊断和治疗。可从四个层面推进。

**（一）立即：评估风险、确保安全**
- 选择安全、私密、不被打扰的环境，在双方都稳定的时间私下谈话，避免在宿舍公开追问。
- 先表达关心并**正常化**："人在痛苦到难以承受的时候出现这样的念头，是很常见的，谢谢你愿意告诉我。"
- **温和而直接地询问**（避免像查清单）："你刚才说想快点结束生命——是偶尔会闪过，还是已经认真想过要怎么做？"据此了解频率、计划、手段与既往尝试。
- **不答应保密**，并说明理由与范围："这件事关系到你的安全，我不能替你保密；但我只会告诉必须知道的人，也会告诉你我要说什么。"
- 立即报告辅导员/学院与学校心理中心；请室友或家人**24 小时陪伴、不让她独处**；危险物品请家长或辅导员协助管理。
- 情况紧急时拨打 **12356（全国）、96525（浙江）**，或直接送最近医院急诊。

**（二）转介：连接专业资源**
- 向她解释抑郁有其生物学基础（神经递质改变），**不是意志薄弱、不是"想不开"**，帮助降低病耻感。
- 告知资源：学校心理健康教育与咨询中心（xlzx.zju.edu.cn，0571-88982525）、校医院心理门诊、精神科门诊（如杭州市第七人民医院）。
- 说明咨询的**专业性与保密性**，提供信息并邀请，尊重她自行决定；**紧急时才陪同**，平时重在陪伴而非替代。
- 可协助预约、陪同初诊，看完医生后继续关注恢复进展。

**（三）持续：朋辈能提供的支持**
- **倾听与共情**：识别情绪、接纳观点、一起感受，**不评论、不分析原因**；不说"想开点""别想太多""你要坚强"。
- **小步行为激活**：固定起床时间；每天吃一顿正餐；每天出门晒太阳 10 分钟；睡前记录一件"今天还行的小事"。
- **低压力社交**：邀请她一起吃饭、散步、自习（并允许她拒绝），而不是笼统地"多参加集体活动"。
- **优势视角**：从具体的小成功切入（"你今天来上课了，这很不容易""你愿意把这些说出来，本身就需要勇气"），**不要**要求她回忆过去的辉煌，那会加重当下的无力感。
- **重建支持系统**：联结室友、好友与家人；与家长沟通时避免指责式表达，帮助她获得理解而非压力。
- **定期跟进**：约定下一次联系时间，重点观察睡眠、进食、社交三项指标的变化。

**（四）边界：朋辈不做什么**
- 不诊断、不治疗、不开药、不替代心理咨询；
- 不承诺保密、不擅自处理危机、不独自承担；
- 不因同情而模糊角色边界（多重关系）；
- 超出胜任力时及时转介，并主动寻求老师与督导支持，做好自我照顾。

**（五）分阶段思路**：紧急期以安全为先（评估、陪伴、报告）；短期以转介与专业治疗为主（就医、遵医嘱、药物与心理治疗配合）；长期以功能恢复与社会支持重建为目标（作息、社交、学业小目标、危机后成长）。

## 例 2 · 「小L」（焦虑 + 学业危机 + 绝望表达型）

> **题干**：小L 近两周情绪低落，常常默默流泪，感到疲惫和无助。临近毕业，对就业过度担忧，注意力不集中，多次缺课，已有挂科。近来胃痛、心脏抽痛，食欲下降，睡眠不规律，常熬夜。朋友圈发过"我没有梦"。朋友和家人的联系变少。

### 一、可能存在什么问题

**总体判断**：小L 同时存在情绪低落、焦虑担忧与心身症状，社会功能（学业、社交）已受损，**提示抑郁与焦虑混合状态**，并出现**绝望表达**，需高度警惕危机风险，建议专业评估。

1. **情绪问题**：情绪低落、默默流泪、疲惫与无助感，符合抑郁特征；对毕业与就业的过度担忧、难以控制，符合焦虑特征。
2. **认知问题**：注意力不集中、难以决策；"我没有梦"属**无望感**表达，是重要的危险信号。
3. **心身症状**：胃痛、心脏抽痛、食欲下降、睡眠不规律——焦虑与抑郁常见的躯体化表现，需排除躯体疾病。
4. **行为与社会功能**：缺课、挂科、熬夜（非适应性应对）、社交减少，学业与社会功能均已受损。
5. **发展性议题**：毕业与就业是典型的发展性危机节点，原有的应对方式不足以应对新任务。

### 二、需要注意哪些风险因素

1. **自杀风险（首要）**：朋友圈"我没有梦"属公开的**绝望表达**，是自杀风险的重要预警信号；叠加情绪低落、社交退缩、躯体症状与学业挫败，风险进一步升高。需评估意念频率、计划、手段、既往尝试。
2. **学业危机升级**：缺课与挂科若持续，可能触发学业警告甚至退学，形成二次打击。
3. **躯体健康风险**：胃痛、心脏抽痛若长期存在，可能发展为慢性健康问题，也需排除器质性疾病。
4. **社会支持减少**：与朋友、家人联系变少，支持系统正在收缩。
5. **非适应性应对固化**：以熬夜应对压力，会加重情绪与躯体症状，形成恶性循环。
6. **保密例外风险**：若其要求对轻生念头保密，不得承诺。

**风险等级：中高。** 应尽快完成风险评估并转介，同时保持高频联系。

### 三、可以做些什么

**（一）先建立关系、稳定情绪**：私下约谈，倾听与共情，正常化其疲惫与无助；不急于给建议、不评判"你想太多"。

**（二）完成风险评估**：温和而直接地询问是否有伤害自己的想法，评估计划、手段与既往史；"我没有梦"要当面澄清，不当作玩笑。

**（三）必要时启动保密例外**：确认风险后及时报告辅导员与心理中心，确保有人陪伴、不独处。

**（四）转介专业资源**：告知学校心理咨询中心与校医院心理门诊，说明专业性与保密性；若焦虑、躯体症状明显，建议精神科评估。提供信息、尊重决定，紧急时陪同。

**（五）朋辈可持续做的**：
- 把"毕业就业"这个庞大压力**拆成可控的小目标**（本周改一版简历、每天投一份），重建掌控感；
- 从**具体做过的事**入手肯定她（而非让她回忆昔日辉煌）；
- 协助恢复规律作息，先固定起床时间，减少熬夜；
- 邀请参加**低压力**的集体活动（一起吃饭、散步），逐步重建社会支持；
- 介绍放松训练：腹式呼吸（每天 2 次、每次 5 分钟）或渐进式肌肉放松，缓解躯体紧张。

**（六）边界**：不诊断、不替代咨询、不承诺保密；自身耗竭时寻求督导与支持。

## 两例的共同结构（可复用的骨架）

```
一、问题：一句定性 → 情绪 / 认知 / 生理 / 行为社会功能 / 发展性议题（4–5 条，每条带案例依据）
二、风险：风险分级 → 自杀（首要）/ 恶化 / 躯体 / 学业 / 支持 / 伦理（5–6 条）
三、帮助：立即安全 → 转介 → 持续支持 → 边界 → 分阶段
```
